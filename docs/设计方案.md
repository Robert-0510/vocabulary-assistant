## 二、词书 Markdown 格式

```markdown
# 我的词书：考研核心词

| 单词 | 音标 | 释义 | 例句 |
|------|------|------|------|
| abandon | /əˈbændən/ | v. 放弃；抛弃 | He abandoned the plan. 他放弃了计划。 |
| benefit | /ˈbenɪfɪt/ | n. 好处 v. 受益 | |
```

解析规则：
- 以表格第一行为表头，跳过第二行分隔线；只识别 4 列，多余列忽略；
- 例句列可留空；有例句时按「首个中文字符」为界拆分为英文句 / 中文翻译；
- 同一词书内重复单词自动去重跳过，返回导入报告（成功数 / 跳过数）；
- 文件编码兼容 UTF-8。

## 三、数据库设计（7 张业务表 + 迁移表）

```sql
CREATE DATABASE IF NOT EXISTS vocab_assistant
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

| new_per_day | INT | 25 | 每日新词量 |

### 6. 数据归属与鉴权
- 所有业务 API（词书 / 学习 / 统计 / 设置）都要求登录，通过 `va_session` HttpOnly Cookie 识别账号；未登录返回 401。
- 词书、设置、学习流水直接带 `user_id`；单词记忆状态通过 `word_states.book_id → word_books.user_id` 间接归属。
- 跨账号访问统一返回 404（不泄露资源是否存在）。
- 注销账号 = 物理删除 `users` 行，数据库外键级联清除会话、设置、词书、单词、记忆状态与学习流水；不做软删除。

## 四、记忆调度算法（FSRS + 扇贝式当日重学）

采用 **FSRS**（Free Spaced Repetition Scheduler，墨墨团队开源、Anki 官方收录的现代间隔重复算法），基于官方 `fsrs` PyPI 包（v6.3.2，默认 21 个权重参数，desired_retention=0.9）。与 SM-2 的差别在于：FSRS 显式建模**记忆稳定性 S / 难度 D / 可提取性 R**，遗忘曲线为幂律形态，根据评分动态更新每个词的下次复习间隔。

### 1. 状态机

```
新词(stability=NULL) ──认识/熟知──► Review ──到期复习──► Review（稳定性持续增长）
        │                          │
        └──不认识/答错──► Learning/Relearning ──答对──┘（当日队列内重学）
```

- `stability` 为 NULL 表示**尚未学习的新词**；一旦作答即进入 Learning 或直接毕业 Review。
- `stability ≥ 90 天` 的词在 UI 上显示为「已掌握」，但仍按 FSRS 到期时间抽查。

### 2. 评分映射（应用交互 → FSRS Rating）

| 交互 | FSRS Rating | 效果 |
|------|-------------|------|
| 不认识 | Again | 未毕业，当日重学，难度上升 |
| 认识 / 答对 | Good | 毕业进入复习，间隔按稳定性增长 |
| 熟知 | Easy | 毕业，间隔跳升 |
| 答错 | Again | 遗忘：lapses+1，难度上升，退回重学 |

（Hard 暂未使用。）学习/重学步进设为单步 1 分钟：保证「不认识/答错」的卡片保持未毕业状态，由前端会话队列当日重学；答对即毕业。

### 3. 新词首次学习初始化
- 自评「认识」（Good）→ 毕业 Review，约 2 天后到期；
- 自评「不认识」（Again）→ 进入详情页（释义+例句+挖空测试），挖空答对（Good）后毕业、约 1 天后到期；当日再快速复查 1 次；
- 自评「熟知」（Easy）→ 毕业 Review，约 8 天后到期抽查。

### 4. 扇贝式当日会话内重复（前端队列状态机实现）
- 新词流程：`自评卡（认识/不认识/熟知）` → 显示释义 →（不认识）`挖空测试` → 队尾快速复查，答对才出队；
- 复习流程：直接 `测试卡`（看英选中 / 看中选英，各 50% 随机；4 个选项由后端从同词书随机抽 3 个干扰项生成）；答错 → 弹详情卡 → 重新回队，直到再次答对；
- 穿插策略：新词 : 复习 ≈ 1 : 2 交替出牌（每 2 个复习插 1 个新词）。

### 5. 今日任务生成（后端）
- 复习池：`stability IS NOT NULL AND due <= 当前 UTC`，按 due 升序、lapses 降序，取 review_per_day 条；
- 新词池：`stability IS NULL` 按 seq 升序取 new_per_day 条。

### 6. 每日任务量档位（新词 : 复习 = 1 : 2）

| 档位 | 新词/天 | 复习/天 | | 档位 | 新词/天 | 复习/天 |
|------|--------|--------|---|------|--------|--------|
| 入门 | 25 | 50 | | 进阶 | 100 | 200 |
| 轻松 | 50 | 100 | | 强化 | 150 | 300 |
| 标准 | 75 | 150 | | 高强度 | 200 | 400 |

另提供两个滑块微调：新词 10~250（步进 5）、复习 20~500（步进 10）。

## 五、后端 REST API

> 除 `/api/health` 与 `/api/auth/*` 外，所有接口都要求登录；未登录返回 401。

### 账号
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/auth/register | 用户名 + 密码注册，自动登录并写会话 Cookie |
| POST | /api/auth/login | 登录 |
| POST | /api/auth/logout | 退出并删除当前会话 |
| GET | /api/auth/me | 当前登录用户 |
| POST | /api/auth/change-password | 修改密码并吊销全部会话 |
| POST | /api/auth/delete-account | 密码确认后硬删除账号及全部数据 |

### 词书
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/books/upload | multipart 上传 .md → 解析入库，返回 {book_id, imported, skipped} |
| GET | /api/books | 词书列表（含各状态词量统计） |
| GET | /api/books/{id}/words?page=&page_size=&keyword=&status= | 分页词表 |
| PUT | /api/books/{id}/words/{word_id} | 词表纠错编辑 |
| POST | /api/books/{id}/reset | 重置该词书的记忆状态与流水 |
| DELETE | /api/books/{id} | 删除词书（级联）；当前词书删除后自动回退 |
| PUT | /api/books/{id}/activate | 设为当前词书 |

### 学习
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/study/today | 生成今日任务 {new_words[], review_words[]}，测试题选项（含 3 个干扰项）由后端生成 |
| POST | /api/study/answer | {word_id, phase, result} → 按 FSRS 更新记忆状态 + 写流水 |
| GET | /api/study/progress | 今日进度（已完成/新词数/复习数） |

### 统计 / 设置
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/stats/overview | 总词数、各状态数、连续打卡、累计天数 |
| GET | /api/stats/calendar?month=YYYY-MM | 打卡日历（每日学习词数） |
| GET | /api/stats/recent?days=30 | 近 N 天学习量曲线 |
| GET / PUT | /api/settings | 读取/更新每日任务量、当前词书 |
| GET | /api/export | 导出带版本号的 JSON 备份 |
| POST | /api/import | 合并导入 JSON 备份 |
| GET | /api/health | 健康检查（数据库 + 版本） |

发音纯前端实现，无后端接口。登录/注册/改密码使用进程内滑动窗口限流。

## 六、前端页面与组件

| 页面 | 路由 | 功能块 |
|------|------|--------|
| 仪表盘 | `/` | 今日任务进度环、打卡日历、连续天数、开始学习入口 |

| 设置 | `/settings` | 档位卡片 + 滑块微调、当前词书切换 |

### 学习页状态机
```
loading → new-intro(自评三键) ──不认识──► new-detail(释义例句) ──► new-quiz(挖空)
                │认识/熟知                              │答对
                ▼                                      ▼
           出队更新状态 ◄──────────────────── 队尾复查一次，答对出队
review-quiz(看英选中/看中选英) ──答错──► review-detail(正确答案) ──► 重新回队
全部完成 → done(今日完成页)
```
- 通用：顶部进度条；发音按钮（喇叭图标）；键盘快捷键：空格=发音，1/2/3=三个按钮；
- 发音实现：`speechSynthesis` 优先（lang='en-US'），不可用或无英文声音时回退 `<audio src="https://dict.youdao.com/dictvoice?type=1&audio={word}">`。

## 八、需要你提前准备的环境（提前量）

1. **Python ≥ 3.11**（安装时勾选 *Add python.exe to PATH*）
2. **Node.js ≥ 20 LTS**（官网 msi 一路下一步）
3. **MySQL 8.x**（安装时记住 root 密码），建库一次：
   ```sql
   CREATE DATABASE vocab_assistant DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```
4. （可选）按第二节格式准备你自己的词书 .md；项目会自带 30 词示例词书，可直接测试

之后启动只需两条命令：
```bash
cd backend && uvicorn app.main:app --reload --port 8000   # 后端 http://localhost:8000/docs
cd frontend && npm install && npm run dev                  # 前端 http://localhost:5173
```
