# 隐私说明

背单词助手是一个**本地运行**的应用。本文说明它会处理哪些数据、数据存放在哪里，以及何时会联网。

## 1. 我们收集什么

- **账号**：用户名与密码哈希（PBKDF2-SHA256，随机盐，260,000 次迭代）。不保存明文密码。
- **学习数据**：你上传的词书、单词、记忆状态（FSRS 参数、到期时间）、学习流水、每日任务设置。
- **会话**：登录后服务端保存会话 token 的 SHA-256，浏览器保存 HttpOnly Cookie。

应用**不包含遥测、统计 SDK、崩溃上报或广告**，不会主动把数据发送给项目维护者。

## 2. 数据存放在哪里

- 源码模式：本机 MySQL 数据库（默认库名 `vocab_assistant`）。
- 打包模式：同一套本机 MySQL；数据库口令保存在 `%APPDATA%\背单词助手\.env`。
- 浏览器 Cookie：仅当前站点会话使用。

删除词书或注销账号会**物理删除**对应数据，不可恢复。注销账号会级联删除会话、设置、
词书、单词、记忆状态与学习流水。

## 3. 何时会联网

以下功能可能访问第三方服务，均由你的浏览器直接发起：

| 功能 | 目标 | 发送内容 | 说明 |
|------|------|----------|------|
| 浏览器语音合成 | 浏览器/操作系统 TTS | 当前单词 | 某些浏览器的语音实现可能使用云端服务，取决于你的系统设置 |
| 发音兜底 | `dict.youdao.com` | 当前单词 | 仅在浏览器没有可用英文语音时请求，用于播放公开的发音音频 |

文档上传、学习记录、统计与账号操作都在本机完成，不经过第三方服务器。

## 4. 备份与导出

导出的备份 JSON 包含你的词书、学习记录与设置。它可能包含个人学习数据，
请存放在安全位置，不要上传到公开仓库或分享给他人。

## 5. 第三方依赖

前端与后端依赖的开源组件见 [LICENSES/THIRD_PARTY_NOTICES.md](../../LICENSES/THIRD_PARTY_NOTICES.md)。
这些组件本身不会主动收集数据；第三方发音服务适用其各自的隐私政策。

## 6. 变更

隐私相关的实现发生变化时，我们会更新本文档并在 [CHANGELOG.md](../../CHANGELOG.md) 中记录。
